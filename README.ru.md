## О проекте

Этот репозиторий содержит интеграцию и автоматизированный пайплайн сборки **OpenTTD 15.3** для браузера и упаковки игры под **Яндекс Игры**.

Исходный код OpenTTD целиком в репозитории не хранится. Во время CI-сборки загружается официальный репозиторий `OpenTTD/OpenTTD` на теге `15.3`, применяются необходимые изменения для веб-версии и Яндекс Игр, после чего игра компилируется через Emscripten и собирается в готовый ZIP-архив.

> Это не официальный релиз OpenTTD. Проект не связан с командой OpenTTD и Яндексом и не является их официальным продуктом.

## Возможности порта

- **WebAssembly-сборка** через Emscripten.
- Инициализация **Yandex Games SDK** в готовом веб-пакете.
- Интеграция **Yandex Loading API** — платформа получает сигнал после запуска рантайма OpenTTD.
- В сборку включены **русский и английский языки**.
- На первом запуске язык автоматически выбирается по локали Яндекс Игр.
- Сборка с **FreeType** для корректного отображения кириллицы.
- Сохранения в браузере через файловую систему Emscripten/OpenTTD.
- В текущий пакет включены свободные базовые наборы **OpenGFX**, **OpenSFX** и **OpenMSX**.
- На выходе формируется **ZIP-архив, готовый для Яндекс Игр**.
- Пайплайн контролирует, чтобы распакованный пакет оставался меньше лимита платформы в **100 МБ**.

## Сборка

Основной способ сборки — GitHub Actions.

1. Открой вкладку **Actions**.
2. Выбери workflow **Final OpenTTD Package**.
3. Запусти его через **Run workflow**.
4. После успешного завершения скачай артефакт `openttd-yandexgames-final`.

Финальный workflow запускается внутри `emscripten/emsdk:3.1.57` и вызывает:

```text
ci/build-final-freetype.sh
```

На выходе создаётся:

```text
openttd-yandexgames.zip
```

## Оригинальный проект

OpenTTD — открытая транспортная экономическая стратегия, которую поддерживает команда OpenTTD.

- Официальный исходный код: [`OpenTTD/OpenTTD`](https://github.com/OpenTTD/OpenTTD)
- Версия, на которую сейчас рассчитан этот порт: **15.3**

По вопросам оригинальной настольной версии, официальной разработки OpenTTD, багов самой игры и официальной документации следует обращаться к проекту OpenTTD.

## Интеграция с Яндекс Играми

Скрипты сборки адаптируют сгенерированную Emscripten-версию под Яндекс Игры. Текущая интеграция включает запуск SDK, передачу локали и уведомление о завершении загрузки, при этом сама OpenTTD сохраняется максимально близкой к официальному исходному коду.

Платформенные изменения применяются во время сборки, а не поддерживаются в виде отдельного постоянно расходящегося форка OpenTTD. Благодаря этому проще проверить, какие именно изменения вносит порт, и воспроизвести сборку на основе нужного релиза.
