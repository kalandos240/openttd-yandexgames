# Third-party notices

This repository builds and packages software and assets maintained by other projects. Their original copyright notices and license terms remain in effect.

## OpenTTD

The game source used by this port is fetched from the official `OpenTTD/OpenTTD` repository, currently targeting release **15.3**.

OpenTTD is distributed under the **GNU General Public License version 2 (GPL-2.0)**. The upstream source tree and release contain the authoritative copyright and licensing information for OpenTTD and components included by upstream.

Upstream repository: https://github.com/OpenTTD/OpenTTD

## OpenGFX

The build pipeline downloads the free OpenGFX base graphics set from the OpenTTD content distribution infrastructure. OpenGFX remains a separate third-party project and retains its own license and copyright notices.

## OpenSFX

The build pipeline downloads the free OpenSFX base sound set. OpenSFX remains a separate third-party project and retains its own license and copyright notices.

## OpenMSX

The build pipeline downloads the free OpenMSX music set. OpenMSX remains a separate third-party project and retains its own license and copyright notices.

## Emscripten and build dependencies

The WebAssembly build uses Emscripten and additional build-time dependencies. Those tools remain subject to their respective upstream licenses.
